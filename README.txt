バレーボールフォーメーション（PWA版）

■ フォルダの中身
  index.html             アプリ本体
  manifest.webmanifest   アプリ名・アイコンの設定
  sw.js                  オフライン動作用（Service Worker）
  lib/                   PDF作成用ライブラリ（ネット接続なしで動きます）
  icons/                 アプリアイコン

■ 使い始めるまで
  PWAは「https://」のWebサーバーに置いたときだけインストール・オフライン動作ができます。
  （index.html をダブルクリックで開いた場合は、通常のWebページとして動きます）
  フォルダごと、次のどれかに置いてください。
   ・GitHub Pages（無料）
   ・校内のWebサーバー（https 対応のもの）
   ・Netlify など（フォルダをドラッグ＆ドロップで公開できます）

■ インストール方法
  ・iPad／iPhone：Safariで開く →（共有ボタン）→「ホーム画面に追加」
  ・Chromebook／Windows（Chrome・Edge）：画面右上の「アプリとしてインストール」ボタン
    またはアドレスバー右側のインストールアイコン
  一度開けば、以後はオフラインでも起動・PDF出力ができます。

■ 更新するとき
  ファイルを差し替えたら、sw.js の1行目付近にある VERSION を
  'vbf-v1.0.1' のように変えてください。利用者の画面に「更新する」ボタンが出ます。

■ データについて
  入力データは端末（ブラウザ）の中に保存され、サーバーには送られません。
  ・ホーム画面のアプリとSafariとではデータが別々になります。
  ・端末の変更やバックアップには、右上の「データ保存」「データ読込」を使ってください。
